# Можливості проєкту

Гілка `experimental` містить стартову 3D-сцену TYMAN на **Godot 4.7.2 .NET** і C#. Сцена завантажує `Main.cs` і виводить `TYMAN C# ready` після запуску. Ігрові механіки ще потрібно розробити.

Проєкт використовує GL Compatibility і має профілі експорту Windows та Linux. Команди запуску й перевірки наведено в [посібнику з розробки](development.md).

Попередній прототип із кристалами описано в [документації GDScript-версії](https://github.com/qwer605/tyman/blob/8b680257955259e2953d99d543657e990e5b55e2/docs/features.md).
